# Personal Portfolio Website 🌐

This is my personal portfolio website built using **pure HTML, CSS, and JavaScript**.  
It showcases my skills, projects, and basic information in a clean and responsive design.

## ✨ Features
- Responsive layout for desktop and mobile
- Smooth scrolling and simple animations
- Projects and skills section
- Clean UI with no frameworks used

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript (Vanilla)

## 🚀 How to Run
1. Download or clone the repository  
2. Open `index.html` in your browser
