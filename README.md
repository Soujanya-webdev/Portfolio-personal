# Personal Portfolio Website

This is my personal portfolio website built using simple web technologies like HTML, CSS, and JavaScript. I created this project to show my skills, projects, and basic information in a clean and easy-to-understand way. The main goal was to keep everything simple, readable, and accessible for anyone who visits the site.

The website is designed to work well on both desktop and mobile devices. It includes smooth scrolling and basic animations to make the experience better without making it too complex. There are sections to display my projects and skills, along with a clean user interface that does not rely on any frameworks.

For this project, I used HTML to structure the content, CSS to design and style the layout, and JavaScript to add interactivity. Everything is built using vanilla code without any external libraries or frameworks.

To run this project, you just need to download or clone the repository and open the index.html file in any web browser. No installation or setup is required.

This project is built as part of my learning journey in web development, and I plan to keep improving it over time as I learn more.
